# 부식재고 사진 분석 설계 메모

Gemma/Gemini 계열 사진 분석은 당장 구현하지 않고 보류한다. 나중에 적용할 때는 휴대폰 부담을 줄이기 위해 상시 실행이 아니라 사용자가 필요할 때만 켜지는 버튼형 구조로 설계한다.

## 목표

- 부식재고 품목을 사진으로 등록할 수 있게 한다.
- 사진 분석은 품명, 수량, 단위, 보관위치 후보를 제안하는 보조 기능으로 둔다.
- 최종 저장 전에는 사용자가 직접 확인하고 수정한다.

## 권장 흐름

1. 부식재고에서 `사진 추가` 또는 `사진 분석` 버튼을 누른다.
2. 카메라 촬영 또는 갤러리 사진 선택을 받는다.
3. 앱에서 이미지를 작은 크기로 압축한다.
4. 사용자가 `분석`을 누른 순간에만 AI를 호출한다.
5. AI가 품명, 수량, 단위, 보관위치 후보를 채운다.
6. 사용자가 확인 후 저장한다.
7. 분석 작업은 즉시 종료하고 백그라운드에서 계속 돌리지 않는다.

## 구현 원칙

- 1차: 사진 첨부, 미리보기, 압축 저장만 구현한다.
- 2차: 사진 분석 버튼을 추가해서 후보값을 생성한다.
- 3차: 필요하면 외부 API나 별도 백엔드를 붙인다.
- GitHub Pages 단독 배포에서는 API 키를 프론트에 넣지 않는다.
- 휴대폰 배터리와 발열을 위해 자동 상시 분석은 사용하지 않는다.

## 보류 사유

- 현재는 부식재고 입력 UX와 취식체크 흐름이 우선이다.
- 사진 AI 분석은 오인식 가능성이 있어 군 부식재고에서는 사용자의 승인 단계를 반드시 둬야 한다.
